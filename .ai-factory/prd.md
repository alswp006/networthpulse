# NetWorthPulse

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
예금·주식·부동산·대출을 수동 입력해 순자산 추이와 목표 달성률을 시각화하는 개인 자산 트래커

## Problem
토스는 연결 계좌 잔액은 보여주지만 부동산·비연동 자산까지 아우르는 통합 순자산 추이와 목표 대비 진행률을 시각화해주는 기능은 없어, 유저가 여러 앱을 오가며 수동으로 자산을 합산해야 함

## Target Users
20-40대 재테크 관심 직장인 및 순자산 관리를 시작한 사회초년생~중년층

## Core Features
1. 자산 항목별 수동 입력(예금/주식/부동산/대출)
2. 월간 순자산 추이 라인 차트
3. 목표 순자산 설정 및 달성률 게이지
4. 리워드 광고 시청 후 자산배분 분석 리포트 공개
5. 순자산 마일스톤 달성 뱃지
6. 주간 체크인 홈 배너 알림

## Monetization
- Model: ads
- Estimated MRR: 약 12만원(DAU 1,200 가정)
- Reasoning: 자산배분 분석 리포트를 리워드 광고 게이팅으로 공개, 목록·차트 화면에 배너 광고 노출
